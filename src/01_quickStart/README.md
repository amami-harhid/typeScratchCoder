# QUICK START

Welcome to Typescratch world.

Typescracher is a game engine written in TypeScript, created with the goal of enabling code-based programming using expressions similar to Scratch 3.

It is ideal for students who have graduated from Scratch 3 and are thinking about starting to learn text-based programming next.

Please take a look at a simple Typescracher sample. 

I would be very happy if you could experience and enjoy how fun it is.
